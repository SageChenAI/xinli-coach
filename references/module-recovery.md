# 模块A：恢复（耗竭急救）

## 触发

能量见底：睡不够/没劲/易怒/不想动/小事就炸。此时**一切认知干预都往后放**，先降档。

## 决策树四问（诊断）

1. **压力源是否持续存在？**（有结束迹象 vs 无休无止）
2. **身体是否高激活？**（肌肉紧、呼吸浅快、睡不踏实）
3. **是否思维反刍？**（无新信息的反复担忧，越想越焦虑）
4. **精力资源是否明显耗尽？**（做事没劲、社交都不想碰）

## 四类干预

| 诊断结果 | 干预 | 做法 |
|---|---|---|
| 持续压力源 | 改变结构 | 建立边界、协商任务、寻求外部支持（说出"我需要"） |
| 身体高激活 | 生理降档 | 循环叹气呼吸（见下）——快速启动副交感神经 |
| 思维反刍 | 认知收口 | 区分有效思考（有新信息）与无效反刍（无新信息）；书写卸载，写完即止，不追求想通 |
| 精力耗尽 | 补充资源 | 睡眠是底层恢复，不可替代；低刺激休息（散步/洗澡/发呆），禁止用刷手机"休息" |

## 循环叹气呼吸法（生理降档）

1. 深吸气（鼻）——吸到七八分满
2. 长呼气（嘴）——比吸气长一倍，发出叹气声
3. 重复 5 轮，即可明显降心率
原理：叹气式呼气延长激活副交感神经（迷走神经），是身体自带的"关机键"。

## 72小时紧急恢复计划（模板）

- **第1天**：循环叹气 ×5轮（早中晚各一次）+ 认知收口书写一次 + 提前1小时上床
- **第2天**：一个结构性动作（对压力源做一件事：说"不"或拆分任务）+ 一次低刺激活动
- **第3天**：一个最小可信行动（见模块B四条件）+ 计划本周的恢复节律

## 三层长期恢复（日常习惯）

1. **身体降档**：固定睡眠时间、日常呼吸练习、每周运动（把动员的能量代谢掉——耗散结构原理：运动是把压力能量转化为成长动力的物理通道）
2. **注意力脱离**：定时数字断联、低刺激爱好（不产出不消耗的任务）
3. **意义系统许可**：允许不完美、允许休息、价值不依赖单次表现

## 压力转化前提（认知底座）

压力可促进成长，但**前提是可承受范围 + 拥有资源 + 有控制权**。三者缺一，先补资源再谈转化——不满足前提时谈"压力即动力"等于耍流氓。
