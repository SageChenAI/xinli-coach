# 模块D：价值（结构层重建）

## 触发

外部评价触发自我否定；把任务失败翻译成人格失败；对评价高度敏感；"我是不是不够好"反复出现。这类问题**不能靠行动解决**（做再多也会被下一次评价击穿），必须先重建评价结构。

## 机制识别（诊断用，讲给用户听）

- **创伤泛化**：早期否定/忽视被内化为自我评判；特定场景的负面评价 → 泛化为对自我价值的否定
- **镜像自我**：自我认知依赖他人反馈；童年"负面镜像"被陌生人的评价激活
- **事/人混淆**：任务失败 ≠ 人格失败。身份标签（草根/牛马等）和外部评价是强化此混淆的放大器

## 三问法（认知重构主工具）

面对一条刺人的外部评价，依次问：

1. **对方评价基于何种事实？**（剥离评价，找事实）
2. **是否存在其他解读？**（至少给出一个更善意的可能）
3. **我的核心价值是否依赖他人认可？**（答案永远是"否"，但要引导用户自己说出）

## 内心法官（康德三条绝对命令）

把裁决权从外部收回自我，但审判必须基于理性——三条命令是审判的宪法：

1. **普遍法则**：我行动的准则，能否成为普遍法则？（对别人也成立吗）
2. **人是目的**：我是否把自己/他人当作手段而非目的？（评价他人/被评价时，人不是评分对象）
3. **意志自律**：我是否由自己的理性立法，而非外部权威？（法官席位在自己手里）

**管辖边界**：内心法官只审价值域（我有价值吗、我的准则正当吗）。日常任务成败归"归因裁判"管（具体/暂时/可调整）——康德法官越界审判日常成败，就是自我苛责。

## 误区表（防跑偏）

| 误区 | 纠正 |
|---|---|
| 把他人评价等同于事实 | 三问法 → 区分事实与评价 |
| 把内心法官当自我苛责工具 | 回到三条命令：审判基于理性与尊重，不是鞭子 |
| 用行动证明价值（考好了就有价值） | 永动机式追逐——价值域问题用价值域方法解决 |
| 价值域问题用"我再努力点"解决 | 先承认：这不是努力问题，是评价结构问题 |

## 终身学习实践（长期建设）

- **每日精进日志**：记录 3 次主动反驳自我否定的思维过程（双轨书写的正向轨）
- **成长型思维**：把挑战视为成长机会；"能力可通过努力提升"是信念也是实验
- **学习系统**：以输出倒逼输入（输出 = 行动 → 反馈 → 证据），建立知识网络与复盘机制
- 深层逻辑：终身学习替代"十年寒窗"的阶段性学习观——评价的参照系从"一次成败"换成"长期轨迹"

## 教学闭环（用户想系统学时按此走）

案例拆解（具体案例：识别触发点→区分事实与评价→重构新叙事）→ 概念讲解（泛化/镜像机制）→ 三问法+康德训练 → 布置实践（精进日志）→ 用评估标准复盘（复述传导链/应用三命令/制定学习计划）。
