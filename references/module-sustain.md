# 模块C：坚持（反馈沉默期）

## 触发

行动已经发生，但足以被人感知的结果尚未出现；在等反馈、开始怀疑、动力衰减。这是**筛选人的阶段**，也是考验心力的关键期。

## 第一步：概念化（认知重构）

- 反馈沉默期 = 行动已发生、结果未显现的必经阶段，**不是失败的信号**
- 外部认可 = 外卖；内部刻度 = 自己做的饭。靠外卖过活的人，在沉默期必饿死
- 习得性无助机制：持续努力无反馈 → 认为无法改变现状。解法不是硬撑，是拆解目标积累小成功

## 第二步：内部刻度设计（反馈炼金）

1. **反馈审计**：觉察自己对外部认可的依赖程度（等赞？等流量？等老师/上司确认？）
2. **刻度设计**：为当前工作设计多维内部评分，每维定细则：
   - 专业维度（如：今天产出的质量 1-5 分，按自定标准）
   - 成长维度（如：今天比昨天多会了什么）
   - 健康维度（如：睡眠/运动/心态）
   - 评分标准必须**自己可判**，不依赖他人确认
3. **反馈转化**：任何外部反馈（包括沉默）都过三层过滤（见下）

## 三层过滤法（处理外部反馈）

1. **事实层**：发生了什么？（可验证的事实，去掉情绪）
2. **意图层**：对方为什么这么说？（动机可能与你无关）
3. **价值层**：这决定我的价值吗？（几乎从不）

沉默也走一遍：事实（没有反馈）→ 意图（可能只是还没到评判点）→ 价值（沉默不否定价值）。

## 第三步：正反馈闭环

- **定义指南针**：一个简单、可观察、可衡量的成功指标（不是宏大目标）
- **拆解小目标**：宏大目标 → 多个小目标，完成即积累成就感
- **记录进步**：动力日记/成功日记，每天记小进步——把经验转化为资产（双轨书写的正向轨）

## 第四步：愿力锚定（燃料层）

引导用户清晰回顾并感受做这件事**最根本的为什么**。把驱动引擎从"目标"升级到"愿力"：
- 目标 = 外挂的里程碑（容易在沉默期失效）
- 愿力 = 内在的为什么（沉默期唯一烧不完的燃料）
- 访谈式提问："这件事最初吸引你的那个点是什么？""如果没人会看到结果，你还会做吗？"

## 心力四力自查（定期）

复原力（倒下能否起来）/ 耐受力（不适能否扛住）/ 专注力（注意力能否收回）/ 内驱力（没有外部推动能否自己动）。
哪力最弱，用哪个模块补：复原→A；专注→物理阻断；内驱→愿力锚定。

## 注意：约哈里之窗的用法

主动寻求反馈可减少盲目区——但**外部反馈是降级为输入，不是升级为主裁判**。以我为主（内部刻度），外部为辅（经三层过滤）。两头摇摆 = 重新变回"等外卖"。
